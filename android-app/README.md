# EXG Forum — Android-приложение

Capacitor-оболочка: `forum.html` лежит **внутри** APK (не открывает ссылку), сетевые запросы идут на ваш сервер форума.

## Сборка через GitHub Actions
1. Положите проект в репозиторий (корень репозитория = папка `jins-forum`).
2. Settings → Secrets and variables → Actions → **Variables** → New: `FORUM_URL` = `https://ваш-сервер` (обязательно https).
   Либо укажите адрес при ручном запуске.
3. Actions → «Build Android APK» → Run workflow.
4. Скачайте артефакт `exg-forum-apk` → `app-debug.apk` → установите на телефон (разрешите установку из неизвестных источников).

## Локально
`python tools/build_forum.py`, затем в `android-app`: `SERVER_URL=https://... npm run prepare-web && npx cap add android && npx cap sync android && cd android && ./gradlew assembleDebug` (нужны Node 20, JDK 17, Android SDK).

## Офлайн
Пока интернет есть, приложение запоминает всё, что вы открывали (ленту, чаты, профили, списки музыки, картинки). Без сети оно открывается и показывает это сохранённое, сверху горит «Соединение…». Как только сервер отвечает, экран обновляется сам. Отправить сообщение/пост без сети нельзя; незагруженные экраны и музыка (стриминг) офлайн недоступны.

## Скачанная музыка и офлайн-волна
- Скачать трек: кнопка ↓ в полном плеере (повторное нажатие — удалить). Всё любимое сразу: «Любимое» → «Скачать». Список и очистка — карточка «Скачанное».
- Файлы хранятся на телефоне (Cache Storage), не стираются при выходе из аккаунта и играют без интернета и без трафика.
- Без интернета на экране EXG Music остаётся одна карточка «Моя волна»: она включает скачанные треки вперемешку по кругу. Остальные разделы скрыты до появления связи. Если сеть пропала посреди прослушивания, плеер сам переключается на скачанное.

## Разрешения
Системное окно «Разрешить?» появляется само, в момент первого использования: камера и микрофон — при записи голосового/видео-кружка и при звонке, камера — при включении видео в звонке, уведомления — при включении «Системные уведомления» в настройках. Если отказать навсегда, приложение подскажет и откроет настройки Android. Код: `tools/android_patch.py` (манифест + `MainActivity`, мост `window.ExgNative`) и `EXGPerm` в `forum.src.html`.
Системные уведомления показываются, пока приложение свёрнуто, но не убито; для закрытого приложения работает дублирование в Telegram.

## Фоновая музыка
Музыка играет при свёрнутом приложении и выключенном экране. В шторке и на экране блокировки — плеер с обложкой, ◀◀ ▶/❚❚ ▶▶, полосой перемотки и кнопкой ✕. Это нативная служба `MusicService` (создаётся `tools/android_patch.py`, тип foreground-service `mediaPlayback`). На Android 13+ нужно разрешить уведомления — приложение спросит при первом включении музыки. Закрыли приложение смахиванием из «недавних» — плеер пропадает.

## Заметки
- Название приложения — «EXG FORUM», иконка из `android-app/icons/` (из вашего логотипа).
- Запросы идут через нативный HTTP Capacitor (`CapacitorHttp`), поэтому CORS на сервере настраивать не нужно.
- Клиент после правок пересобирайте (`tools/build_forum.py`) — workflow делает это сам.
- Это debug-APK. Для публикации в магазине нужна подпись релизного ключа (keystore в Secrets) — скажите, добавлю.
- Иконка и название по умолчанию — замените через `@capacitor/assets`, если нужно.
